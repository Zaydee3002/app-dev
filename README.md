# Sword Art Online

**Plot:**
*Sword Art Online is a plot about players trapped in a virtual reality MMORPG where death in the game means death in real life, forcing them to clear 100 floors to escape. The main characters, Kirito and Asuna, must navigate this deadly game world, which unfolds into different arcs and introduces other VR games and threats.*

**Characters:*
*Kirigaya Kazuto*
*Alice Zuberg*
*Eugeo*
*Asuna*
*Sinon*
